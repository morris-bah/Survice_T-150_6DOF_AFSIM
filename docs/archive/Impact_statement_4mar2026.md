**Impact of AI-Assisted Development on Modeling and Simulation: T-150 UAS Case Study**

The National Ground Intelligence Center (NGIC) Model and Simulation Division identified the need for a higher fidelity, physics-based UAS model and behavior-capable simulation to answer key intelligence questions for the intelligence community, using the Advanced Framework for Simulation, Integration and Modeling (AFSIM). To address this need, NGIC explored opportunities to increase development efficiency and effectiveness by leveraging Claude and Claude Code CLI AI systems for code generation and dynamic model development. Open-source research was conducted on the T-150 Heavy-Lift UAS system to establish approximately 65 UAS parameters, 6 Degree-of-Freedom physics behaviors, and scenario-specific testing concepts, which were then provided to Claude AI to construct the required models, simulations, scenarios, and plugins. This effort produced five custom C++ AFSIM plugins comprising over 7,700 lines of production code, 31 test scenarios, and comprehensive verification and validation documentation -- all within approximately 20 hours of active development across a 57-day calendar span.

The results of this initial exploration demonstrated both the significant potential and the practical realities of AI-assisted model development:

- The initial model, built using native AFSIM functionality, was architecturally sound but lacked the required fidelity, necessitating iterative plugin development to achieve physics-based accuracy.
- Development required a moderate level of manual intervention by developers to resolve key technical issues, including plugin registration patterns, coordinate conversion errors, and motor efficiency calibration.
- Claude was able to generate extensive, excellent documentation with only minor edits required, significantly reducing the documentation burden that typically accompanies complex simulation projects.
- Configuration management through Claude Code is near-automatic and extremely effective, allowing faster iteration on requirement changes. The same can be said for generating scenario-specific adaptability, where new test scenarios and flight patterns were rapidly produced and modified.

Through leveraging AI -- not just Claude, but AI development tools broadly -- it is likely that production timelines for modeling and simulation efforts of this nature can be reduced from months to weeks. However, the use of AI systems such as Claude and Gemini requires further exploration and testing to define appropriate use of AI and identify inherent risks of this evolving technology when applied to Modeling and Simulation of threats. The priority in this investigation was defining possibilities; minimal Test and Evaluation was executed against the simulation outputs themselves. Our initial conclusion is that AI-assisted development is a force multiplier for defense software engineering, and continued investigation into its application, limitations, and risk profile within the M&S domain is warranted.
