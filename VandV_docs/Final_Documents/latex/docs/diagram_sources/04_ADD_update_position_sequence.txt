## Section: 3.7 UpdatePosition Sequence
## Description: Detailed per-timestep execution sequence for the Rotorcraft6DOF_Mover's
##   UpdatePosition() method. This is the core physics loop showing: dt computation,
##   air density update, navigation (spline or waypoint), control mixing, per-rotor
##   update with motor lag, force aggregation (thrust, drag, external forces, gravity),
##   rigid body integration (Newton-Euler), and state synchronization back to AFSIM.

UpdatePosition(simTime)
  |
  +--> Compute dt = simTime - mLastSimTime
  |
  +--> Update air density from altitude (ISA model)
  |
  +--> IF spline navigation enabled:
  |      UpdateSplineNavigation(dt, simTime)
  |    ELSE:
  |      UpdatePositionHold(dt)   -- waypoint tracking
  |      UpdateAltitudeHold(dt)   -- altitude PID
  |
  +--> ApplyControlMixer()
  |      Maps throttle/roll/pitch/yaw commands to per-rotor RPM
  |      RPM_i = hover_RPM * (throttle + roll*mix_i + pitch*mix_i
  |              + yaw*mix_i)
  |
  +--> FOR EACH rotor:
  |      rotor.Update(dt, airDensity, groundEffectFactor)
  |        Motor first-order lag:
  |          actualRPM += (cmdRPM - actualRPM) * dt / tau
  |        Compute thrust, torque, power from actualRPM
  |
  +--> ComputeTotalThrustForce()    -- sum rotor thrust vectors
  +--> ComputeTotalRotorMoment()    -- sum rotor moments
  +--> ComputeDragForce(bodyVel)    -- aerodynamic drag
  +--> ReadExternalForces()         -- slung load + weapon forces
  +--> ReadExternalMoments()        -- weapon moments from AuxData
  |
  +--> Add gravity in world frame, rotate to body frame
  +--> Sum all forces and moments
  |
  +--> mRigidBody.Integrate(totalForce, totalMoment, dt)
  |      Compute linear acceleration: a = F / m
  |      Compute angular acceleration:
  |        alpha = I^{-1} (M - omega x I*omega)
  |      Integrate velocity, position (Euler method)
  |      Integrate quaternion: q_dot = 0.5 * q * omega
  |      Normalize quaternion, update Euler angles
  |
  +--> UpdateDynamicMass()   -- weapon ammo + slung load mass
  +--> SyncToAFSIM()         -- copy 6DOF state to WsfPlatform
  +--> PublishTelemetry()    -- write state to AuxData
