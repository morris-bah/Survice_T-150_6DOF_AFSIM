## Section: 7.2 Pendulum Integration Loop
## Description: Per-timestep execution sequence for the SlungLoadProcessor's
##   Update() method. Shows: state check, velocity/acceleration reading,
##   pendulum dynamics integration (angular accelerations from gravity +
##   aircraft acceleration + damping, semi-implicit Euler), cable tension
##   computation, load position calculation, reaction force computation
##   (Newton's 3rd law), resonance detection, and AuxData publication.

  Update(simTime):
    IF loadState is DETACHED or RELEASED:
      return (no dynamics to compute)

    dt = simTime - mLastUpdateTime

    Read platform velocity from mover state
    Compute aircraft acceleration by finite differencing velocity

    UpdatePendulumDynamics(dt, accelX, accelY, accelZ)
      Compute angular accelerations:
        theta_x'' = -(g/L)*sin(theta_x) - (a_x/L)*cos(theta_x)
                    - c*theta_x'
        theta_y'' = -(g/L)*sin(theta_y) - (a_y/L)*cos(theta_y)
                    - c*theta_y'
      Integrate with semi-implicit Euler:
        theta_x' += theta_x'' * dt
        theta_y' += theta_y'' * dt
        theta_x  += theta_x'  * dt
        theta_y  += theta_y'  * dt

    ComputeCableTension(accelZ)
      T = m * sqrt((g + a_z)^2 + (L*theta_x'')^2
          + (L*theta_y'')^2)

    ComputeLoadPosition()
      Convert swing angles to Cartesian offset from attach point

    Compute reaction forces on aircraft (Newton's 3rd law):
      F_x = -T * sin(theta_x)
      F_y = -T * sin(theta_y)
      F_z = -T * cos(theta_x) * cos(theta_y)

    CheckResonance(dt)
      Track zero crossings to measure swing frequency
      Flag if swing angle exceeds resonance threshold

    Publish all state to AuxData (forces, angles, tension, position)
