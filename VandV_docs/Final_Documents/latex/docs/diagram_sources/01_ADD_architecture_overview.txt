## Section: 3.1 Architecture Overview

##   loosely-coupled component architecture within the AFSIM runtime. Shows the
##   WsfPlatform containing the Rotorcraft6DOF mover, the AuxData store (shared
##   blackboard), and four WsfProcessor plugins (Battery, Propulsion, VRS, Slung Load).
