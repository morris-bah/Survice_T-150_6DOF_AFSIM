## Section: 5.1 Inter-Plugin Data Flow Diagram
## Description: Comprehensive data flow diagram showing all AuxData key exchanges
##   between the 5 T-150 plugins. Shows producer/consumer relationships:
##   - 6DOF Mover publishes 6dof_total_power, velocity/attitude telemetry;
##     consumes SLUNG_FORCE_X/Y/Z and WEAPON_FORCE/MOMENT
##   - Battery Processor consumes 6dof_total_power and PROP_TOTAL_POWER (fallback);
##     publishes BATTERY_SOC, BATTERY_VOLTAGE, BATTERY_POWER_W
##   - Propulsion Processor publishes PROP_TOTAL_POWER, PROP_TOTAL_THRUST, etc.
##   - Slung Load Processor publishes SLUNG_FORCE_X/Y/Z, SLUNG_CABLE_*, SLUNG_SWING_*;
##     consumes platform velocity via GetVelocityNED()
##   - VRS Processor publishes VRS_MARGIN, VRS_STATE, VRS_LIFT_FACTOR;
##     consumes platform velocity via GetVelocityNED()
