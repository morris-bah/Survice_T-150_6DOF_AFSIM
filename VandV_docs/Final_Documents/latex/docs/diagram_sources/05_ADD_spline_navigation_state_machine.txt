## Section: 3.8 Spline Navigation State Machine
## Description: State machine for the Catmull-Rom spline navigation system.
##   Governs transitions between APPROACHING, AT_WAYPOINT, ROTATING, and DEPARTING
##   states. When a waypoint is reached, the behavior type (FLY_THROUGH, SLOW_PASS,
##   or STOP_AND_HOVER) determines the transition path. STOP_AND_HOVER enters
##   AT_WAYPOINT for a configured hover duration, then optionally ROTATING before
##   DEPARTING. FLY_THROUGH and SLOW_PASS go directly to DEPARTING.

Statechart: SplineNavState

    +---> APPROACHING ---[reached P2]--->+
    |         |                          |
    |         |                   [check behavior]
    |         |                     /    |     \
    |         |            FLY_THROUGH SLOW   STOP_AND
    |         |              |       _PASS    _HOVER
    |         |              |         |         |
    |         |              |         |         v
    |         |              |         |    AT_WAYPOINT
    |         |              |         |      |  [duration elapsed]
    |         |              |         |      v
    |         |              |         |    ROTATING
    |         |              |         |      |  [heading achieved]
    |         |              v         v      v
    |         |              +----DEPARTING---+
    |         |                     |
    |         +-----[advance cache]-+
    |                               |
    +-------------------------------+
