## Section: 4.3 Power Source Resolution
## Description: Fallback chain for the Battery Processor's power source resolution.
##   Shows the 4-level cascade: (1) configured power_source_key (default
##   PROP_TOTAL_POWER), (2) 6dof_total_power from the 6DOF mover, (3)
##   PROP_TOTAL_POWER from the propulsion processor, (4) static hover_power_w
##   fallback. This ensures the battery works regardless of which plugins are loaded.

  Read power from AuxData:
    1. Try mPowerSourceKey (configurable, default "PROP_TOTAL_POWER")
    2. If not found or zero, try "6dof_total_power" (from mover)
    3. If not found or zero, try "PROP_TOTAL_POWER" (from propulsion)
    4. If none available, use mHoverPowerW (static fallback)
