## Section: 7.3 SlungLoad State Machine
## Description: State machine for the Slung Load Processor. States: DETACHED,
##   ATTACHED, SWINGING, RESONANCE, RELEASED. Load attachment starts dynamics,
##   increasing swing transitions through warning states, and ReleaseLoad()
##   can transition from any attached state to RELEASED.

Statechart: SlungLoadState

    DETACHED --[AttachLoad(mass)]--> ATTACHED
                                      |
                              [swing > threshold]
                                      v
                                   SWINGING
                                      |
                              [resonance detected]
                                      v
                                   RESONANCE
                                      |
    RELEASED <--[ReleaseLoad()]-- any attached state
