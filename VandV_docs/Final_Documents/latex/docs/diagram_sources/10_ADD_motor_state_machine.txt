## Section: 5.4 MotorState Machine
## Description: State machine for individual motor state transitions in the
##   PropulsionProcessor. States: OFF, STARTING, RUNNING, OVERTEMP, FAILED.
##   Linear progression from OFF through STARTING to RUNNING. Temperature
##   monitoring can transition RUNNING to OVERTEMP, and persistent overtemp
##   leads to the terminal FAILED state.

Statechart: MotorState

    OFF --[power on]--> STARTING --[RPM > idle]--> RUNNING
                                                     |
                                          [temp > limit]
                                                     v
                                                  OVERTEMP
                                                     |
                                          [temp still high after timeout]
                                                     v
                                                   FAILED
                                                  (terminal)
