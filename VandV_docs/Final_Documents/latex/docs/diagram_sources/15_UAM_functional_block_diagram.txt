## Section: 3.1 Model Functional Block Diagram
## Description: Top-level functional block diagram of the T-150 simulation model
##   showing all five plugin components and their data flow through the AFSIM
##   AuxData key-value store. The 6DOF Mover (physics engine) sits at the top
##   containing RigidBody6DOF, RotorModel[8], and FlightController sub-blocks.
##   Below it, the Propulsion, Battery, and VRS processors communicate through
##   AuxData, with the Slung Load processor feeding forces back up.
