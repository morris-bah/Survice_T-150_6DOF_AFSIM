## Section: 6.2 VRS State Machine
## Description: State machine for the Vortex Ring State (VRS) Processor.
##   5 states: CLEAR, CAUTION, ONSET, DEVELOPED, RECOVERY. Transitions are
##   driven by the VRS margin value (0-1, lower = closer to VRS). The cycle
##   goes CLEAR -> CAUTION -> ONSET -> DEVELOPED -> RECOVERY -> CLEAR.
##   Recovery requires sustained margin improvement over recovery_time.

Statechart: VRSState

    CLEAR --[margin < caution_threshold]--> CAUTION
      ^                                       |
      |                            [margin < onset_threshold]
      |                                       v
      |                                     ONSET
      |                                       |
      |                       [development_time elapsed]
      |                                       v
      +---[recovery_time elapsed]--- RECOVERY <--- DEVELOPED
                                       ^               |
                                       +---[exit VRS]--+
