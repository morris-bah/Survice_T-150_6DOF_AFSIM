\section{\unclass Model Testing}

\subsection{\unclass Scopes of Test Cases}

\unclass \tref{FamiliesScopes} summarizes each test case’s purpose and lists which components affect the outcome of the test.  \tref{FamiliesScopes} shows how this table would appear in OD5's TDD.

\guidance{

\unclass TIMELINE: Should be started by PDR and finalized at CDR.

\unclass Each test case has its own row.  Briefly state the purpose of the test case.  List which components participate in the test.  

Example: \unclass suppose “Test 3” ensures that the tracking logic calculations are correct.  Test 3 may use runtime position information from the model’s receiver, or it may use canned data imported from a file.  In the first case, the receiver would be listed as a dependent component because it has to work correctly for Test 3 to pass.  The receiver is not a dependent component in the second case because Test 3 would pass even if the receiver is broken.  One purpose of this column is to show whether Test 3 needs to be rerun if the receiver changes somehow later, after Test 3 was run the first time.}
