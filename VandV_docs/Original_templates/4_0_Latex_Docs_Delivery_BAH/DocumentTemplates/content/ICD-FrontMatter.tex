	\unclass TIMELINE: MOST ITEMS: Ready by SRR, finalized by PDR.  REVISION NUMBERS \& DATES: Finalized at FDR.
	
	\unclass ``Prepared By'' and ``Classified By'' must be a company name, not an individual's name
	
	\unclass All dates are in YYYYMMDD format, both ``Date'' and  ``Declassify On'' (unless the declassification is not on a specific date). 
	
	\unclass If the document is classified, the Classification Block should be, ``Classified By:'', ``Derived From:'', ``Declassify On:''.  If the document contains CUI, the CUI Block should be, ``Controlled By:'', ``CUI Category(ies):'', ``Limited Dissemination:'', ``POC:'', ``Contact:''. Unclassified documents have no Classification Block, and documents without CUI have no CUI Block.
	
	\unclass ``Distribution/Dissemination Controls'' line is only needed if the document contains CUI material
